## 附录 A：竞品参考与证据要求

### A.1 使用原则

- 对标条目必须记录产品版本、验证日期、官方来源、实测环境和适用版本。
- 未经实测的官网宣传不得转换为清盘的验收要求。
- 专有产品只参考可观察行为，不复制代码、规则文件、UI 素材或商标表达。
- 开源项目的代码或规则若需复用，必须先确认精确版本许可证、通知义务和衍生作品要求；当前未批准直接复用。

### A.2 能力参考

下表仅是待研究线索，不构成已核实事实或需求证据：

| 线索 ID | 候选产品/类别 | 拟研究方向 | 明确不作的推断 | 当前状态 |
|---|---|---|---|---|
| LEAD-001 | Windows Cleanmgr / Storage Sense | 目标 build 的受支持入口、任务调度、系统集成 | 使用系统 API 等于无风险 | 仅线索 |
| LEAD-002 | TreeSize 类磁盘分析工具 | 占用展示、排序、逐层分析交互 | 分析结果等于可安全删除内容 | 仅线索 |
| LEAD-003 | BleachBit 类本地规则工具 | 规则表达、预览、删除模式区分 | SSD 多次覆写可保证物理擦除 | 仅线索；许可证待查 |
| LEAD-004 | CCleaner / Wise 类综合工具 | 应用覆盖、预览和任务体验 | 注册表项或旧驱动可按通用规则安全删除 | 仅线索；不进入 V1 默认范围 |

### A.3 竞品证据登记模板

每条可引用证据必须独立登记，不能只填写“类工具”。当前文档不填入未经验证的版本、行为或许可证结论。

| 证据 ID | 产品、精确版本/构建与通道 | 验证日期 | 来源类型、链接与访问日期 | 测试环境与复现步骤 | 观察结果、失败与恢复行为 | 适用限制与需求 ID | 许可证/SPDX、复用范围与法务结论 | 证据位置、状态与复核人 |
|---|---|---|---|---|---|---|---|---|
| 待分配 | 必填 | 必填 | 必填 | 必填 | 必填 | 必填 | 涉及复用时必填 | 必填 |

证据状态固定为“仅线索、官方文档确认、单环境实测、矩阵复验、待复验、已失效”。官网宣传最多标为“仅线索”；“未观察到”不能写成“不支持”。产品大版本或目标 Windows build 变化后，相关证据自动转为“待复验”。性能比较只有在相同硬件、数据集、轮次和测量方法下才可登记为结果，否则只能描述可观察交互。

## 附录 B：风险登记表

| 风险 | 严重度 | 当前控制 | 剩余工作 |
|---|---|---|---|
| 永久删除用户数据 | 严重 | 显式选择、快照复检 | V1 前接入隔离并收敛默认入口 |
| 规则供应链被篡改 | 严重 | 当前规则编译进代码 | 实现 Ed25519 规则包、撤销和回滚 |
| 规则用户态高水位被同 SID 回退 | 高 | 签名与能力包络仍限制动作 | 状态异常失败关闭；记录同 SID 威胁限制，不把 ACL 描述成进程隔离 |
| QPC1 隔离/清除中途崩溃或容器损坏 | 严重 | 当前仅有 `temp` 同卷明文 preview、哈希链日志和只复制导出；无 QPC1/清除 | copy/full-verify/delete WAL、content guard、DPAPI/AEAD vectors、固定根/父链句柄、启动对账、R4 分能力门禁 |
| WebView 伪造自动批准 | 严重 | 自动任务尚未实现 | 原生确认、后端 `approvalGrantId`、运行时重验 |
| 提权接口扩大攻击面 | 严重 | 当前主要为用户权限 | 设计一次性执行器和受限 IPC |
| 更新 manifest 重放或 MSI 验签后替换 | 严重 | 更新器端点/公钥尚未配置 | 单调签名 manifest、高完整性暂存、精确 LKG 日志 |
| 在线服务只有客户端 mock、无可审计交付 | 严重 | 三项服务设计/owner/origin 当前 blocked | `ServiceDeliveryRecord`、SVC/M1-SVC 追踪、staging/production contract/packet/E2E 与日志删除证据 |
| SSD 擦除误导 | 高 | 尚未实现 | V2 按介质能力分流并限制承诺 |
| 明文审计泄露路径 | 高 | 本地文件、字段有限 | 字段最小化、ACL、DPAPI 和保留策略 |
| 授权开发旁路进入生产 | 高 | 仅开发用途 | 构建门禁、静态扫描和系统安全存储 |
| 云占位触发下载或远端删除 | 高 | 当前扫描排除多类占位 | 为所有写入口建立统一云属性检查 |
| “闲置文件”误判 | 中 | 仅提示和人工选择 | 文案标记低置信度，不允许自动化 |
| 性能指标不可复现 | 中 | 有资源硬上限 | 建立固定数据集和批准基线 |

## 附录 C：术语

| 术语 | 定义 |
|---|---|
| 允许列表 | 明确声明允许根、匹配方式、风险和动作的规则集合 |
| 候选 | 扫描得到、尚未获得执行授权的对象 |
| 快照 | 扫描时记录的路径和文件身份等证据 |
| 清理计划 | 用户选择候选后生成的单次、限时、不可变执行输入 |
| 失败关闭 | 无法确认安全条件时停止或跳过，不尝试强制继续 |
| 重解析点 | Windows 符号链接、Junction、挂载点等可能改变路径解析的对象 |
| 隔离 | 先复制到 QPC1 认证加密容器并完整解密验证，再提交容器和单次移除原目录项；V1 不还原原位置、不因导出删除隔离源，隔离内容仍占用空间 |
| QPC1 | V1 隔离容器逐字节格式；AES-256-GCM 分块、DPAPI CurrentUser 包装 DEK、确定性 framing 和 closed manifest，详见第 5.5 节 |
| content guard | 绑定源句柄的 oplock/break 证据；只有目标平台的真实 writable mapped-view fixture 证明可观察并发写时才允许 R2 源删除 |
| sourceRetained | QPC1 容器完整且原文件仍存在的失败终态；固定显示“两份内容均保留”，可导出或经独立 R4 计划只清除容器，不得自动重试源删除 |
| MachineUninstallJournal | 由受保护 machine broker 维护的全机卸载事实源，使用唯一资源索引和全局 mutex，跨管理员共享同一 OS 调用 |
| MachineUninstallAttachment | 将某一 owner 的本地 operation/plan/item 安全绑定到既有 machine 卸载 attempt 的记录；只允许 owner 读取其脱敏投影 |
| MachineFullInstallerJournal | 完整安装的全机耐久事实源；只有 `admitted/callArmed/inFlight/resolvedWithoutCall/resolved/recoveryRequired` 六态。可信恢复使 journal 进入 `resolved(completionKind=trustedRecovery)`，但保留 embedded 原 attempt 的 `recoveryRequired` 历史 |
| 停用授权密钥 | 与日常设备 PoP key 分离、要求 Windows Hello 或高保护 CNG 用户验证的非导出密钥；只签一次性 challenge 绑定的停用声明 |
| InstallRecoverySource | `appUpdate/fullInstaller/productUninstall` 的闭合恢复来源联合；assessment、文件 grant、恢复包、attempt 和 resolution 必须逐字段绑定同一来源 |
| VerifiedProductAbsenceEvidence | 绑定预期产品身份并证明 MSI 注册、产品服务和目标二进制均 absent 的闭合证据；只有该证据允许产品卸载进入 `uninstalledPreserved` |
| ServiceDeliveryRecord | 绑定在线服务 owner、设计、不可变制品/部署、契约、持久化、信任、隐私、运行手册和测试证据的发布记录 |
| 回收估算 | 按明确 basis 计算的非负 `reclaimedBytes`，不等于候选逻辑大小或卷级观测差值 |
| 可用空间变化（观测） | 受影响卷在整个操作窗口前后的有符号可用空间差值，可能含同期系统 I/O，不宣称精确归因 |
| 能力包络 | 编译进应用的规则权限上限；远程规则只能收窄，不能扩大 |
| 批准 grant | 后端在原生确认后签发的自动化授权记录；公开哈希/绑定内容本身不是授权凭据 |
| tombstone | 内容清除后保留的最小操作事实，不含原路径、安全描述符、仓库名或内容哈希 |
| 最后已知良好版本 | 规则候选激活失败时继续使用的当前 active 包；应用更新另可使用高完整性日志绑定的精确上一已签名版本回滚。已被更高规则序号取代的旧槽不自动恢复为 LKG |
| R1-R4 | 从可重建缓存到不可逆操作的风险等级，详见第 5.4 节 |
